## 规则

- Tag 以中文为主，可保留稳定英文锚点。
- 不要为一次性临时现象随意发明 Tag。
- 新 Tag 必须能复用，并落入项目、任务类型、视觉问题、资产状态、执行状态或审批状态之一。
- 涉及客户身份、私密路径或密钥的内容不得成为 Tag。
