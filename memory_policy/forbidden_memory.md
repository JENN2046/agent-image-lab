# 禁止写入长期记忆清单

## 绝对禁止

- API key
- token
- cookie
- 账号密码
- 私密绝对路径
- 客户身份信息
- 客户未公开产品细节
- 客户原图完整描述
- 图片二进制
- 系统内部密钥
- VCP 配置私密字段

## 禁止作为事实写入

- 未经确认的核心风格规则
- 单次 AI 推测
- 插件偶发失败结论
- 未经人工确认的审美判断
- 一次插件失败就得出的长期插件结论
- 没有 `case_id` 的风格规则
- 没有评分依据的入库判断
- 没有来源的用户偏好

## 处理方式

发现上述内容时，`memory_delta.write_mode` 必须设为 `forbidden` 或 `audit_only`，并在 `rejection_reason_cn` 中用中文说明原因。
