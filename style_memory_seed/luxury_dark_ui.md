# Luxury Dark UI 风格种子

> 这是 Git 中的风格种子，不等于 VCP 长期记忆。它只记录已经在 Photo Studio OS 中明确的高级黑方向。

## 适用范围

用于 Photo Studio OS、商业级指挥中心、审片台和高级黑界面方向的视觉约束。

## 核心特征

- 近黑背景，避免纯黑死板。
- 深冷蓝底色，提供冷静、专业、技术感。
- 冷白细字体，保证信息清晰和克制。
- 光效低亮度，不能过曝。
- 警示色使用克制橙红，只用于风险、报警、关键状态。
- 空间秩序清楚，不堆叠装饰卡片。

## 禁止方向

- 不要发灰。
- 不要过亮。
- 不要过度蓝光。
- 不要大面积霓虹。
- 不要赛博朋克。
- 不要游戏 HUD。
- 不要普通 SaaS。
- 不要廉价科幻。
