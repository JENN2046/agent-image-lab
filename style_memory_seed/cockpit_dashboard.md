# Cockpit Dashboard 风格种子

> 这是 Git 中的风格种子，不等于 VCP 长期记忆。它用于约束 Photo Studio OS 的仪表盘空间关系。

## 核心特征

- 仪表盘必须有清晰中心焦点。
- 中央大仪表承担主视觉焦点。
- 左右小仪表与中央大仪表距离平衡。
- 右侧小仪表不得贴近侧栏。
- 机械深度、玻璃反射、刻度和指针必须克制清晰。
- 下方信息模块服务于主仪表，不抢主视觉。

## Photo Studio OS 对齐规则

- 三仪表中心构图。
- 右侧保留 Risk Pulse / Approval Queue。
- 下方保留 Project Execution / Activity Timeline / AI Inspection Feed。
- 克制橙红警示。

## 禁止方向

- 不要把仪表做成普通圆形进度条。
- 不要破坏三仪表平衡。
- 不要让右侧仪表贴近侧栏。
- 不要游戏 HUD。
- 不要赛博朋克。
- 不要普通 SaaS 仪表盘。

## 记忆边界

这些规则仅为风格种子和案例复查依据。升级为核心风格记忆前，必须经过 ImageLab_Master / Archivist_Agent / 人工审核。
