# Photo Studio OS 风格记忆种子

> 这是 Git 中的风格种子，不等于 VCP 长期记忆。进入 VCP 长期记忆需要 Review Console 或等价人工审批。

## 核心视觉铁律

- 16:9 widescreen。
- 高级黑，近黑背景，深冷蓝底色。
- 冷白细字体，克制、清晰、像专业操作系统。
- 三仪表中心构图。
- 中央大仪表是视觉焦点。
- 左右小仪表与中央大仪表距离平衡。
- 右侧保留 Risk Pulse / Approval Queue。
- 下方保留 Project Execution / Activity Timeline / AI Inspection Feed。
- 克制橙红警示，只用于风险、报警、关键状态。

## 禁止方向

- 不要赛博朋克。
- 不要游戏 HUD。
- 不要普通 SaaS。
- 不要发灰。
- 不要过亮。
- 不要过度蓝光。
- 不要大面积霓虹蓝光。
- 不要紫色高饱和光污染。
- 不要廉价科幻。
- 不要破坏三仪表平衡。
- 不要让右侧仪表贴近侧栏。

## 归档与记忆边界

- 本文件只保存已明确的风格种子。
- 不允许写未经确认的新规则。
- 不保存图片二进制。
- 不保存客户隐私、私密路径、API key、token、cookie 或密码。
- 写入 `Photo_Studio_OS_Style_Memory` 前必须经过 ImageLab_Master / Archivist_Agent / 人工审核。
