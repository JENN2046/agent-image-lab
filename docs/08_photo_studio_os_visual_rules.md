# 08 Photo Studio OS 视觉铁律

## 核心规则

- 16:9 widescreen。
- 高级黑，近黑背景，深冷蓝底色。
- 冷白细字体，克制、清晰、像专业操作系统。
- 三仪表中心构图。
- 中央大仪表是视觉焦点。
- 左右小仪表与中央大仪表距离平衡。
- 右侧保留 Risk Pulse / Approval Queue。
- 下方保留 Project Execution / Activity Timeline / AI Inspection Feed。
- 克制橙红警示，只用于风险、报警、关键状态。

## 禁止方向

- 不要赛博朋克。
- 不要游戏 HUD。
- 不要普通 SaaS。
- 不要发灰。
- 不要过亮。
- 不要大面积霓虹蓝光。
- 不要紫色高饱和光污染。
- 不要廉价科幻。

## 风格关键词

```text
高级黑、近黑背景、深冷蓝、冷白细字、三仪表、中央大仪表、摄影工作室指挥中心、克制橙红警示、精密 OS、非赛博朋克、非游戏 HUD、非普通 SaaS。
```

## 资产入库要求

图片必须同时满足：三仪表结构稳定、中央焦点明确、右侧栏不挤压仪表、高级黑不发灰、警示色克制、文字 / UI 可读。

## 记忆写入要求

这些规则在 Git 中作为风格种子存在。进入 `Photo_Studio_OS_Style_Memory` 时，必须经过 ImageLab_Master / Archivist_Agent / 人工审核。
