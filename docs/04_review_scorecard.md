# 04 Review Scorecard

## 评分表

| 维度 | 分值 | 说明 |
|---|---:|---|
| 构图与空间关系 | 15 | 主体、仪表、右侧栏、底部模块的空间秩序。 |
| 主体清晰度 | 10 | 中央大仪表和核心视觉焦点是否明确。 |
| 风格一致性 | 15 | 是否符合 Photo Studio OS 高级黑、冷白 UI、三仪表规则。 |
| 高级感 / 商业质感 | 15 | 是否像专业摄影工作室指挥中心，而非普通 SaaS。 |
| 细节控制 | 10 | 仪表刻度、指针、玻璃、金属、线条是否克制。 |
| 色彩与光线 | 10 | 黑度、冷白、深蓝、橙红警示是否平衡。 |
| 文字 / UI 可读性 | 10 | 字体、标签、数字和模块名称是否清楚。 |
| 迭代潜力 | 10 | 是否值得继续精修。 |
| 资产沉淀价值 | 5 | 是否值得进入案例库 / 风格记忆。 |

## 分数解释

| 分数 | 判断 |
|---:|---|
| 95-100 | 核心样板，必须入库。 |
| 90-94 | 高质量资产，建议入库。 |
| 85-89 | 候选资产，继续精修。 |
| 75-84 | 方向可用，但问题明显。 |
| 60-74 | 仅供参考。 |
| 60 以下 | 不建议继续。 |

## 人工评分规则

人工评分覆盖 AI 评分。人工审批覆盖 Agent 建议。人工未确认时，不得正式入库，不得写核心风格规则。
