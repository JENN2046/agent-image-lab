# Photo Studio OS Command Center Prompt

## 中文目标

生成一张 16:9 的 Photo Studio OS 高级黑三仪表指挥中心视觉图。

## 视觉规则

- 16:9 widescreen。
- 高级黑，近黑背景，深冷蓝底色。
- 冷白细字体，克制、清晰、像专业操作系统。
- 三仪表中心构图，中央大仪表是视觉焦点。
- 左右小仪表与中央大仪表距离平衡。
- 右侧保留 Risk Pulse / Approval Queue。
- 下方保留 Project Execution / Activity Timeline / AI Inspection Feed。
- 克制橙红警示，只用于风险、报警、关键状态。
- 禁止赛博朋克、游戏 HUD、普通 SaaS、过亮、发灰、廉价科幻。

## 英文执行提示词示例

premium dark photography studio command center UI, near-black background, deep cold blue undertone, cold-white thin typography, three analog gauges, central large gauge as focal point, restrained orange-red risk alerts, professional cockpit dashboard, not cyberpunk, not gaming HUD

## 中文解释

以上英文用于控制高级黑、冷白字体、三仪表和专业指挥中心气质；不是 DailyNote 正文。
