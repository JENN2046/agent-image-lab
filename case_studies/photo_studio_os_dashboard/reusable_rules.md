# Reusable Rules

## MVP 样例可复用规则

以下规则来自 Photo Studio OS MVP 样例评审，是 Git 中的案例总结，不等于 VCP 长期记忆。进入长期记忆前必须经过人工审批。

## 构图规则

- 三仪表必须保持横向平衡。
- 中央大仪表必须是视觉焦点。
- 左右小仪表与中央大仪表距离必须均衡。
- 右侧小仪表不得贴近 Risk Pulse / Approval Queue 侧栏。
- 右侧栏不得挤压三仪表主构图。

## 风格规则

- 保持 16:9 widescreen。
- 保持高级黑、近黑背景、深冷蓝底色。
- 使用冷白细字体。
- 克制橙红警示，只用于风险、报警、关键状态。

## 禁止方向

- 不要赛博朋克。
- 不要游戏 HUD。
- 不要普通 SaaS。
- 不要发灰。
- 不要过亮。
- 不要过度蓝光。
- 不要破坏三仪表平衡。
- 不要让右侧仪表贴近侧栏。

## 记忆写入状态

当前规则仅为案例总结和风格种子候选。是否写入 `Photo_Studio_OS_Style_Memory` 必须经过 Review Console 或等价人工审批。
